Will hold the Logisim/Digital circuit files (`.circ`) for the GhanaCore-5
datapath and control unit: register file, ALU, the five pipeline registers
(IF/ID, ID/EX, EX/MEM, MEM/WB) with the exact fields listed in
[`../docs/opcode_format_table.md`](../docs/opcode_format_table.md), hazard/
forwarding logic, and instruction/data memory pre-loaded with the assembled
[MoMo routine](../docs/momo_routine.md) for simulation.
